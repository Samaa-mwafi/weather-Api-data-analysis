🌦️ Weather API Data Analysis Project
📌 Project Overview
This project focuses on collecting, cleaning, analyzing, and visualizing weather data using a public Weather API. The goal is to extract meaningful insights

about temperature trends, humidity, wind speed, and other atmospheric conditions over time to support data-driven decisions.

🎯 Project Objectives
Fetch real-time and historical weather data using an API

Clean and preprocess raw weather data

Perform exploratory data analysis (EDA)

Identify trends and patterns in weather conditions

Build visual dashboards and reports for insights

🛠️ Tools & Technologies
power query – Data cleaning & transformation

Power BI – Data visualization

Requests – API data collection

Weather API (Visual Crossing / OpenWeather / etc.)

🔄 Project Workflow (Step by Step)
1️⃣ Data Collection

Connect to the Weather API using an API key

Send HTTP requests to retrieve daily/hourly weather data

Store the raw data in CSV or JSON format

2️⃣ Data Cleaning

Handle missing and null values

Convert date and time columns to proper datetime format

Correct data types for numeric columns

Remove duplicates and irrelevant columns

3️⃣ Data Preprocessing

Feature engineering (year, month, season, day)

Normalize or scale numerical features if needed

Create calculated fields (temperature difference, feels-like gap, etc.)

4️⃣ Exploratory Data Analysis (EDA)

Analyze temperature, humidity, wind speed, and precipitation

Study seasonal and monthly trends

Identify extreme weather conditions and anomalies

5️⃣ Data Visualization

Line charts for temperature trends

Bar charts for averages

Heatmaps for seasonal patterns

Interactive dashboard (Power BI)

6️⃣ Insights & Reporting

Summarize key findings

Detect climate trends and anomalies

Provide business or environmental recommendations

📊 Key Insights Examples

Hottest and coldest months of the year

Seasonal temperature variations

Relationship between humidity and precipitation

Wind speed trends across seasons


✅ Results

Clean and structured weather dataset

Analytical insights about weather behavior

Interactive dashboard for better decision-making
